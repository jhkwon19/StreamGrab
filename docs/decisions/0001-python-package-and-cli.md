# ADR 0001: Python 패키지와 표준 라이브러리 CLI 사용

- 상태: 승인
- 날짜: 2026-08-18

## 배경

초기 프로젝트는 빠르게 실행 가능한 CLI가 필요하지만, 아직 복잡한 명령 체계나
외부 프레임워크 기능은 필요하지 않다.

## 결정

- Python 3.11 이상을 지원한다.
- 패키지는 `src` 레이아웃과 `pyproject.toml`로 구성한다.
- 초기 CLI와 TOML 파서는 각각 `argparse`, `tomllib`을 사용한다.
- 런타임 의존성은 기능상 필요해질 때 추가한다.

## 결과

설치와 테스트 환경이 단순하고 패키지 소스가 작업 디렉터리에서 우연히 import되는
문제를 줄인다. 향후 하위 명령이나 풍부한 UI가 필요해지면 CLI 프레임워크 도입을
별도 ADR로 검토한다.
