# ADR 0003: 단계별 Generic 우선 Extractor 파이프라인

- 상태: 승인
- 날짜: 2026-08-18

## 배경

웹 영상은 표준 미디어 태그, HLS·DASH manifest, JSON 설정, iframe, 브라우저
네트워크 요청 등 여러 위치에 나타날 수 있다. 한 페이지에 서로 다른 영상이나 한
영상의 여러 품질이 함께 존재할 수도 있다. 발견되는 사이트마다 조건문을 CLI에
추가하면 분석과 다운로드가 결합되고 유지보수가 어려워진다.

## 결정

- URL과 페이지 구조를 단계별로 분석한다.
- 표준 구조를 다루는 Generic Extractor를 항상 우선한다.
- 발견 결과는 공통 후보 모델로 정규화한 후 중복 제거와 콘텐츠 그룹화를 거친다.
- Site Extractor는 범용 분석으로 표현할 수 없는 도메인 규칙에만 사용한다.
- 브라우저 분석은 비용과 보안 영향을 고려해 마지막 단계로 둔다.
- Downloader는 후보가 어떤 Extractor에서 왔는지 알 필요가 없도록 유지한다.
- 두 번째 독립 Extractor를 추가할 때 Protocol과 Registry를 도입한다.

## 결과

새 사이트 지원이 기존 Downloader를 변경하지 않으며, 사이트 변경의 영향도 해당
분석 단계에 제한된다. 여러 영상과 품질을 올바르게 표현하기 위한 모델 확장이
필요하지만, 실제 manifest 분석 전에 추측성 필드를 대량 추가하지 않는다.
